# Drum sample attribution

## Real recorded samples (from Tone.js acoustic-kit)

These six samples are sourced from the Tone.js audio repository, which in turn
attributes them to Chris Wilson's [web-audio-samples](https://github.com/cwilso/web-audio-samples)
project. Origin URL:

  https://github.com/Tonejs/audio/tree/master/drum-samples/acoustic-kit

Files:

- `kick.wav`        — from `kick.mp3`
- `snare.wav`       — from `snare.mp3`
- `hihat_closed.wav`— from `hihat.mp3`
- `tom_hi.wav`      — from `tom1.mp3`
- `tom_mid.wav`     — from `tom2.mp3`
- `tom_floor.wav`   — from `tom3.mp3`

Converted from MP3 → mono 44.1 kHz 16-bit WAV with `ffmpeg`.

The Tone.js and cwilso repositories do not declare an explicit license file.
These samples have been publicly distributed and reused as part of
Web Audio API demos and the Tone.js library for over a decade. If this app
ever ships commercially, the samples should be re-sourced from a known
CC0 or licensed-for-commercial-use pack.

## Procedurally synthesized samples

These five sounds are generated by `tools/gen_drum_wavs.py` in this repo
using sine waves, filtered noise, and resonant peaks. They are not
recordings of real instruments.

- `hihat_open.wav`
- `crash.wav`
- `ride.wav`
- `click_high.wav`
- `click_low.wav`
